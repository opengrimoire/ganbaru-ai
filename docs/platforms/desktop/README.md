# Desktop platforms

Linux and Windows host the complete local application, including native coding-agent execution, authorized working folders, terminals, Git, desktop media, browser native messaging, and platform-specific Doomscrolling adapters.

The desktop process also owns the embedded private-LAN vault coordinator. Data settings create short-lived Android pairing QR invitations and show the linked device, current ownership role, read-only refresh, transfer retry, unlink, and explicit recovery actions. The coordinator has no general remote command, SQL, or arbitrary file interface. It runs only with the desktop application and supports one enrolled Android phone and one vault.

When Android owns the vault, desktop keeps its last complete copy available read-only. `Use on this device` requests the current Android snapshot through the coordinator and advances ownership only after staging and validation. Desktop browser and application Doomscrolling usage continues in a bounded device-local spool and joins the owner's combined counter when the LAN connection is available.
